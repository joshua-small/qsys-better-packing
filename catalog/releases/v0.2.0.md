Better Packing 0.2.0

Requires Q-SYS Mods Core 0.1.6 or newer within 0.1.x, Q-SYS Mod Manager 0.8+, and the exact supported Designer 10.5 build. Better Shortcuts is optional.

The four native Pack directions use Better Packing by default and retain one canonical action and their existing shortcuts. One Preferences checkbox restores all four native implementations without resetting user bindings. Legacy standalone assignments migrate to their native actions, preserving distinct alternatives and overwrite consent. Existing opt-outs survive migration. Center operations remain separate unbound actions; packing geometry is unchanged.

The new 0.2 package range enforces the updated Core dependency while retaining every historical 0.1.x package and approval. Windows CI now runs the existing 11 shared-router checks alongside the 18 geometry checks. Prior disposable Designer acceptance covers the four physical root-schematic shortcuts and native opt-out. Remaining menu, UCI and broader context acceptance stays in issue #2; this release does not claim new Designer or hardware coverage.

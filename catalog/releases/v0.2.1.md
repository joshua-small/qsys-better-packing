Better Packing 0.2.1

Choose Native or Better Packing separately for each element category in the Schematic and UCI editors, under File > Preferences > Better Packing. Defaults keep Better Packing for schematic components and Layout items, and native packing for schematic graphics/controls and every UCI category. A mixed selection uses native packing when any selected category is Native. Existing saved gaps, shortcuts and the master opt-out are retained.

Opted-in controls, headers, text, group boxes, images and polygons use the saved gap. Polygon packing accounts for vertex offsets from the model origin, including fractional offsets, without changing the vertices. All six native Pack commands now share the routing policy; former standalone center shortcuts migrate to their native equivalents. The explicit Better Packing window continues to apply enhanced packing independently of the routing choices. Groups, Flexboxes, unlisted types and component control panels retain native handling.

Requires Q-SYS Mods Core 0.1.6 or newer within 0.1.x, Q-SYS Mod Manager 0.8+, and the exact supported Designer 10.5 build. Better Shortcuts is optional. The fast Alt + right-drag gap HUD remains future work.

Validation includes 25 portable contract checks and 23 Windows WPF routing/selection checks. Scoped native Designer evidence and remaining acceptance limits are recorded in docs/ELEMENT-PACKING.md and issue #2. This release makes no hardware or deployed-UCI claim.

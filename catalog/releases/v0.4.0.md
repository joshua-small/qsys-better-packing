Text Controller grid transpose.

Preview complete rectangular control-family rows copied from one Text Controller onto a schematic, then apply a position-only transpose. Family labels become column headers and control indices become rows. The saved Gap and drawn item dimensions determine spacing. Controls retain their identities, bindings, sizes, styles and orientations.

Cancel makes no changes. Apply revalidates the selection and uses one undoable operation. Incomplete or ambiguous grids, unequal counts, mixed controllers, locked items and unsupported canvases are rejected. UCI transpose, arbitrary grids and collision checks against unselected objects are outside this feature.

Also rejects nonfinite pin coordinates before pin packing can move any object. Existing native/Better Packing routing preferences are retained.

Requires Mods Core 0.1.10 or newer within 0.1.x. Bounded native checks on Designer 10.5.0 cover preview/cancellation, position-only Apply, physical Undo/Redo, stale/rejection guards and save/reopen. A further 27 focused checks passed on Designer 10.5.1 with Core 0.1.11, including Preview/Cancel, Apply, physical Undo/Redo, native UCI selection rejection and fresh-process persistence. Fractional size requests settled to whole-unit drawn bounds on both versions, so actual fractional drawn-size acceptance remains unverified. A controlled UCI-containing document replacement exited both with and without Better Packing in the tested configuration. That route remains unaccepted; other modules were present, so this is not an unmodified Designer baseline. These checks do not establish general compatibility; startup opt-in alone does not establish feature acceptance.

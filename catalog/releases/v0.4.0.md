Review candidate: Text Controller grid transpose.

Preview complete rectangular control-family rows copied from one Text Controller onto a schematic, then apply a position-only transpose. Family labels become column headers and control indices become rows. The saved Gap and drawn item dimensions determine spacing. Controls retain their identities, bindings, sizes, styles and orientations.

Cancel makes no changes. Apply revalidates the selection and uses one undoable operation. Incomplete or ambiguous grids, unequal counts, mixed controllers, locked items and unsupported canvases are rejected. UCI transpose, arbitrary grids and collision checks against unselected objects are outside this feature.

Also rejects nonfinite pin coordinates before pin packing can move any object. Existing native/Better Packing routing preferences are retained.

Requires Mods Core 0.1.10 or newer within 0.1.x. Native acceptance of this candidate remains pending; startup opt-in on an untested Designer build does not establish compatibility.
